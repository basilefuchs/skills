# Labels de triage

Les skills raisonnent avec cinq rôles de triage canoniques. Ce fichier associe chaque rôle au label réellement utilisé dans le système de tickets de ce dépôt.

| Label dans mattpocock/skills | Label dans notre dépôt | Signification                                   |
| ---------------------------- | ---------------------- | ----------------------------------------------- |
| `needs-triage`               | `needs-triage`         | Le mainteneur doit évaluer cette issue          |
| `needs-info`                 | `needs-info`           | En attente d'informations de l'auteur           |
| `ready-for-agent`            | `ready-for-agent`      | Entièrement spécifiée, prête pour un agent seul |
| `ready-for-human`            | `ready-for-human`      | Demande une implémentation humaine              |
| `wontfix`                    | `wontfix`              | Ne sera pas traitée                             |

Quand un skill mentionne un rôle (par exemple « appliquer le label prêt pour un agent »), utiliser le label correspondant de ce tableau.

Modifier la colonne de droite pour l'adapter au vocabulaire réellement utilisé.
